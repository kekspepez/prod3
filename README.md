# Student Desk

Локальный учебный органайзер для Windows. Интерфейс на русском языке, тёмная тема.

## Возможности
- Добавление предметов и выбор формы аттестации: зачёт или экзамен.
- Работы разных типов: лабораторная, коллоквиум, практическая, курсовая, домашнее задание, проект и другое.
- Два независимых статуса: «Выполнено» и «Сдано».
- Заметки отдельно у каждой работы.
- Дедлайны и приоритеты.
- Поиск по предметам и работам, фильтры, список просроченных.
- Архив предметов и восстановление из архива.
- Прикрепление нескольких файлов к работе и открытие вложений.
- Сводная статистика на главном экране.
- Автоматическое локальное хранение в SQLite.

## Где хранятся данные
После запуска база данных и вложения сохраняются в:
`%LOCALAPPDATA%\StudentDesk\`

Это не папка проекта. Поэтому данные не пропадут при переносе или обновлении программы. Для резервной копии закрой приложение и скопируй папку `StudentDesk` из `%LOCALAPPDATA%`.

## Сборка EXE на Windows
1. Установи Python 3.11 или новее с сайта https://www.python.org/downloads/
2. При установке Python включи опцию **Add Python to PATH**.
3. Распакуй архив проекта в отдельную папку.
4. Дважды нажми `build_windows.bat`.
5. После завершения открой `dist\StudentDesk\StudentDesk.exe`.

Сборка создаёт папку приложения (onedir), а не один файл. Это надёжнее для Qt-приложений: рядом с EXE будут необходимые библиотеки. В дальнейшем папку `dist\StudentDesk` можно перенести целиком.

## Запуск из исходников
Открой терминал в папке проекта и выполни:
```bash
python -m pip install -r requirements.txt
python student_desk.py
```

## Важное
- Проект подготовлен как исходный Windows-проект со скриптом сборки. Сам Windows EXE нужно собрать на Windows-машине: сборка PyInstaller для Windows из Linux/macOS не создаёт корректный Windows EXE.
- Удаление предмета из архива удаляет также его работы и прикреплённые файлы. Архивирование ничего не удаляет.
- Прикреплённые файлы копируются в локальную папку приложения; оригиналы в исходных местах не меняются.

## Сборка EXE через GitHub Actions (без Windows)
1. Создай репозиторий на GitHub и загрузи в него все файлы проекта (включая папку `.github`).
2. Открой вкладку **Actions** → **Build Windows EXE** → **Run workflow** (сборка также запускается при каждом push).
3. После завершения (около 3–5 минут) открой запуск и скачай архив **StudentDesk-windows** из раздела **Artifacts**.
4. Распакуй архив и запусти `StudentDesk.exe`. Папку нужно переносить целиком.
